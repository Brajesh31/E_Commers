## ## ✨ Project Overview

This project is a comprehensive e-commerce platform built from the ground up to replicate the core functionalities of modern online stores. It features a rich user interface for customers to browse products and a dedicated admin dashboard for store owners to manage inventory, orders, and users.

The application is designed with a focus on performance, security, and user experience, integrating a robust backend with a dynamic, responsive frontend. It includes everything from user authentication to payment processing with Stripe.

## ## ⭐ Core Features

### For Customers 🛍️
* **User Authentication**: Secure sign-up, login, and profile management using JWT.
* **Product Catalog**: Browse, search, and filter products by category, price, and other attributes.
* **Product Details Page**: View detailed product information, images, and reviews.
* **Shopping Cart**: Add/remove items and update quantities in a persistent shopping cart.
* **Secure Checkout**: A multi-step checkout process with integrated Stripe payments.
* **Order History**: View past orders and their statuses in a personal dashboard.

### For Administrators 👩‍💻
* **Admin Dashboard**: A secure, dedicated panel for managing the entire store.
* **Product Management**: Full CRUD (Create, Read, Update, Delete) functionality for all products.
* **Inventory Management**: Update stock levels for products.
* **Order Management**: View all customer orders, update their status (e.g., "Processing," "Shipped").
* **User Management**: View and manage all registered customer accounts.

## ## 🚀 Getting Started

To get a local copy up and running, follow these detailed steps.

### ### ✅ Prerequisites

* **Node.js** (v18.x or later)
* **npm** & **Git**
* **MongoDB**: A running instance of MongoDB, either locally or a connection string from MongoDB Atlas.

### ### ⚙️ Installation & Setup

1.  **Clone the repository**:
    ```sh
    git clone [https://github.com/Brajesh31/E_Commers.git](https://github.com/Brajesh31/E_Commers.git)
    ```
2.  **Navigate to the project directory**:
    ```sh
    cd E_Commers
    ```
3.  **Backend Setup**:
    * Navigate to the backend directory: `cd server`
    * Install backend dependencies: `npm install`
    * Create a `.env` file in the `server` directory and add the environment variables listed below.
    * Start the backend server: `npm start`

4.  **Frontend Setup**:
    * Navigate to the frontend directory from the root folder: `cd client`
    * Install frontend dependencies: `npm install`
    * Start the frontend development server: `npm start`
